# 🗺️ Interactive Indian Art Map

An interactive web application exploring the geographic spread and cultural influence of India's greatest art traditions — spanning ancient rock-cut cave murals, temple architecture, sacred bronzes, Mughal and Pahari miniatures, and living folk crafts.

![Interactive Indian Art Map Preview](ajanta.jpeg)

## ✨ Features

- **Interactive Leaflet Map**: Smooth navigation across India with custom markers denoting key historical sites.
- **Categorized Art Traditions**: Filter landmarks by category including Cave Paintings, Temple Architecture, Sculpture, Folk Art, and Miniature Paintings.
- **Rich Informational Overlays & Cards**: In-depth historical background, regional context, and imagery for 13 landmark heritage sites.
- **Responsive & Modern UI**: Tailored typography, sleek glassmorphism components, and fluid layout designed for both desktop and mobile screens.

## 🚀 Getting Started

No build step or complex dependencies required.

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ArjitSharma19/Interactive-Map.git
   ```
2. Open `index.html` directly in your browser, or serve it locally:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Or using Node.js npx serve
   npx serve .
   ```
3. Open `http://localhost:8000` in your browser.

## 🌐 Deploy to GitHub Pages

1. Navigate to your repository settings on GitHub: `Settings` > `Pages`.
2. Under **Build and deployment** > **Source**, select `Deploy from a branch`.
3. Choose the `main` branch and `/ (root)` folder, then click **Save**.
4. Your site will be published live at `https://arjitsharma19.github.io/Interactive-Map/`.
